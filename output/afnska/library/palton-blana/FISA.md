# Fișă produs – Palton cu corset și blană detașabilă (afnska „Пальто с корсетной вставкой” + set blană)

Sursă: instagram.com/p/DfXtVJcRXuy (afnska_dress) + catalog afnskadress.ru/palto (id 99579254)

## Ce este
Palton lung de lână, croit pe talie, cu fusta evazată (clos) până la jumătatea gambei.
La spate are corset cu șiret (se strânge pe talie). Guler mare și manșete din blană pufoasă, DETAȘABILE (se cumpără separat, se prind de palton).

## Detalii (din fișa lor)
- Material: stofă de palton (lână), netedă, nu matlasată.
- Talie: insert de corset la spate, cu șiret – „formează silueta”; paltonul se poate lua și fără corset.
- Temperatură: până la −10 °C fără căptușeală suplimentară; până la −25 °C cu căptușeala călduroasă adăugată.
- Blană: set guler + manșete, se cumpără separat de palton.
- Culori palton: alb, negru, vișiniu (burgundy), ciocolatiu.
- Culori blană: alb, negru, vișiniu, ciocolatiu.
- Mărimi: S / M / L, pe înălțimi 160 cm și 170 cm.
- Preț la ei: 34 990 RUB paltonul (~350–420 $); blana separat.
