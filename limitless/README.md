# LIMITLESS

Sistemul care transformă organic dropshipping-ul într-o mașină: **research → hook → producție video → QA → montaj → postare → cifre → învățare**, fiecare pas automatizat, măsurat și îmbunătățit continuu.

**Ținta: 5.000.000 $ în sezonul de iarnă 2026** (vezi `docs/00-viziune.md` pentru calculul din spatele cifrei).

## Principii
1. **Dovedit pe cifre, nu pe impresie.** Un hook, un stil, o regulă intră în sistem doar când cifrele reale (retenție, vizualizări, click-uri, comenzi) o confirmă.
2. **Fiecare pas manual devine un modul.** Ce face un om de două ori, sistemul face a treia oară.
3. **Volum × calitate.** Zeci de videouri pe zi, fiecare la nivel ultra-realist, verificat vizual înainte de livrare.
4. **Cunoașterea se adună, nu se pierde.** Tot ce aflăm (de la noi și de la cei mai buni dropshipperi organici) devine regulă datată în `docs/`, cu sursa.
5. **Multi-produs.** HeatGrump e primul produs; motorul e construit ca orice produs nou să intre cu un singur fișier în `products/`.

## Structura
| Folder | Ce conține |
|---|---|
| `docs/` | viziunea, pipeline-ul, regulile, roadmap-ul |
| `playbooks/` | metodele celor mai buni dropshipperi organici + ale lui Szasz, structurate și comparate |
| `products/` | câte un fișier per produs (referințe, unghiuri, public, prețuri) |
| `library/` | hook-uri dovedite, virale analizate, muzică, fonturi, clipuri de mișcare |
| `engine/` | modulele automate (research, producție, montaj, QA, feedback, postare) |
| `.claude/skills/` | comenzile pe care Claude le execută când Szasz le cere |
