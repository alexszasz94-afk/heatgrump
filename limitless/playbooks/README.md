# Playbook-uri

Aici adunăm metodele celor mai buni dropshipperi organici de acum + metodele lui Szasz. Câte un fișier per sursă (`playbooks/<nume>.md`), toate pe același șablon, ca să le putem compara și să extragem ce e comun și dovedit.

Regulă: intră doar ce e observat (link, captură, cifră) sau spus explicit de sursă. Nimic inventat.

## Șablon
```
# <Nume / cont>
Sursa: <link-uri, curs, video, discuție> · Data: <...>
Rezultate declarate / vizibile: <...>

## Produs
cum aleg produsul, preț, marjă, sezon
## Conturi
câte, ce nișă, cum le încălzesc, ce platforme
## Hook-uri
tipare, primele 3 s, text pe ecran, audio
## Format video
durată, structură, montaj, muzică
## Volum
câte videouri/zi, ce automatizează
## Conversie
link în bio, pagina, ofertă
## Ce preluăm în LIMITLESS
<lista concretă, fiecare cu modulul în care intră>
```
