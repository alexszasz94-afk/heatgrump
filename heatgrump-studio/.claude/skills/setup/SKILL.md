name: setup
description: First run / "start" — checks the computer tools, the Higgsfield connection and credits, and uploads all reference files to Higgsfield once (IDs saved in state/media.json). Run when the creator types start, setup, or before the first video.
---
1. Run `bash setup/check.sh`. If something is missing, install it yourself:
   - macOS: `brew install ffmpeg yt-dlp` (if `brew` is missing, install Homebrew with the official one-line command from brew.sh, then retry), `python3 -m pip install --user pillow numpy faster-whisper librosa demucs`.
   - Windows: `winget install Gyan.FFmpeg` and `winget install yt-dlp.yt-dlp`, `py -m pip install pillow numpy faster-whisper librosa demucs`. On Windows use `py` where the docs say `python3`.
   - Linux: `sudo apt-get install -y ffmpeg python3-pip && pip install --user yt-dlp pillow numpy faster-whisper librosa demucs`.
   Run the check again until everything says OK.
2. Higgsfield: call `balance`. If the Higgsfield tools are missing or fail, tell the creator: "Type /mcp, choose higgsfield, press Enter and log in to your Higgsfield account in the browser that opens, then type start again." Stop until it works.
3. Read `state/media.json` (create `{}` if missing). The robe is Grinch. For every file of THAT robe that has no id yet, upload it (see "Uploading a local file" in CLAUDE.md) and save the id under the key shown:
   - its 2 B-roll motion clips (videos): `grinch_v4` ← `motion/grinch-v4.mp4`, `grinch_v5` ← `motion/grinch-v5.mp4`
   - Grinch images: they are ALREADY in Higgsfield — copy the ids from products/grinch/PRODUCT.md into state/media.json (no upload needed).
   For each file: `media_upload` (ONE file per call), then `python3 engine/tools.py put <file> '<upload_url>'` (must print 200 — no curl lines to paste), then confirm: one `media_confirm` with `type: "video"` for the motion clips and one with `type: "image"` for the image ids. Save state/media.json after every file so nothing is uploaded twice if something stops.
4. **If the creator's first message is already a job (a reel link or an idea): give a 3-line version of the explanation below and start the video right away (rule 31 Oct, Alex).** Otherwise: **Explain EVERYTHING to the creator, directly here in the chat (rule 28 Oct, Alex: "after they press set me up, explain exactly everything we do and how — directly in Claude").** Not a link, not "read the PDF": write it in the chat, in simple English, friendly, short paragraphs with a bold title each, no jargon, no commands, never credit numbers or prices. Cover all of this, in this order:
   1. **You're ready.** Everything is installed; roughly how many videos they can make now (balance ÷ ~60, said as "about N videos"; ≥ 2× more when they reuse a B-roll).
   2. **What you get.** A finished vertical video (Reels/TikTok), always in the same order: hook (the first 3–7 s that stop the scroll) → she puts the robe on → steps into the foot pockets → the heating cable clicks in → the remote lights go up → cozy ending. A new woman and a new room every time, music (Christmas songs) with the beat drop on the cut after the hook, quiet music under the hook so the voice stays on top.
   3. **What you do — only 2 things.** (a) Send a reel that works for someone else (link) — or tell me your own hook idea in a sentence. (b) When the video is ready, open it in CapCut, add the text I suggest (exact words + emojis, top of the screen, the whole video) and post it. The video comes without text on purpose: text you add yourself looks like a real person's post.
   4. **How I copy a reel.** I watch it frame by frame, write down every second and every object, remake it with our woman, our room and our robe at the same seconds, remove their caption, and remake their voice line (same words, same seconds, on her lips). Their brand objects become ours (e.g. their box → our box with our logo).
   4b. **Start frame first = more professional (Alex 28 Oct).** For hooks it is often better to first make ONE photo of the first moment (our woman, our room, our robe or box), show it to them, fix it until they like it, and only then animate it into the video. Tell them: "When you want a hook to look really pro, say 'start frame first' — I'll show you the first picture, you approve it, then I animate it. It takes a few minutes more but looks much more professional." For their own ideas this is always the way.
   5. **How I check.** I look at every image and every clip myself before you see anything: face, robe, hood, hands, feet in the pockets, no extra frames, sound and words, music. If something is wrong I redo it alone; you never have to spot mistakes. If I can't make something perfect, I tell you exactly what.
   6. **Save credits — 2 more hooks.** After every video I'll offer: "send me 2 more reel links and I'll make them on the same B-roll" — those videos only need a new hook, so they cost about half. You can also ask for a different cozy ending on them.
   7. **Rooms, faces, updates.** Rooms come in zips from Alex: drag the zip here and say "add these rooms". New faces I find myself. When Alex sends an update zip, drag it here and say "install the update" — your videos stay.
   8. **What works best.** Short reels (10–20 s) with lots of views and a strong first 3 seconds: reveals, countdowns, unboxings, try-ons, reactions. Try one hook idea of your own every 2–3 copied reels, change the cozy ending often, post every day and tell me which hooks get the most views.
   9. **Things you can say anytime** (a short list): "fă asta cu Grinch: <link>", "I have an idea: …", "use this song" (drag an MP3), "the hood looks wrong at the end", "give me 3 hook ideas", "how many videos can I still make?".
   End with one line: "Trimite-mi primul link de reel și începem." Also mention once that the full illustrated guide is HOW-IT-WORKS.pdf in their folder, if they ever want to read it again.
