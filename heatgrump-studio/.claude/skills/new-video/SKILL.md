---
name: new-video
description: Makes one finished, ready-to-post robe video (also for "new hook <robe>: <idea>" — the creator's own hook, see CLAUDE.md) (Grinch) from an Instagram/TikTok link or a hook idea — hook start frames, hook clips, new B-roll with a new person and room, fixed connector/remote clips, trimming, edit with text and music. Run when the creator types "new video ...".
---
Work alone from start to finish. After EVERY image and EVERY clip run the skill `check` and repair alone before moving on; run it again on the final video before delivering. Keep the creator updated with one short line at each stage ("making the start frames…", "animating…", "editing…").

0b. **Own hook** (the creator describes an idea of their own instead of sending a link): follow "Creator's own hook" in CLAUDE.md for the hook (start frame → show it → animate as they say), then continue from step 3 here.
0a. **Cozy ending = CLASSIC by default — never wait (rule 31 Oct, Alex).** Unless they already wrote `cozy: ...`, use the B-roll's own wide cozy shot. In your first status line add one short sentence: "If you'd like a different cozy ending this time (e.g. reading a book, hot cocoa), just tell me." — suggest one that is not in the last 3 of `tools.py history`. Do not stop for an answer.
0. If `state/media.json` lacks the robe keys → run the `setup` skill first. The robe is always Grinch. Check `balance` (≥ 80 credits). Run `python3 engine/tools.py history` — this video must be DIFFERENT from the last 3 in hook concept, outfit, music cue and on-screen text (variety = the account doesn't look repetitive).
1. **Reference**: link → `python3 engine/tools.py download <url> output/_new/ref` (download failed and the creator put the video in `inbox/` → the same command with `inbox/<file>.mp4` instead of the link) and `sheet` it (1.5 fps); Read the sheet. Idea only → pick a proven concept in `HOOKS.md` that is NOT in the last 3 of `history` and adapt it. Make a 10 fps sheet of the hook part and write a timeline of every action with its second and speed (HOOKS.md step 3b) — you will paste it into the hook prompt. Decide: hook shots (1–4); hook length = EXACTLY the original's hook end (CLAUDE.md rule 9o; only an idea without a reference is 3–7 s); the on-screen text (CLAUDE.md rule 9: word for word, ONLY their product/character name swapped for ours); whether it's a "whole clip" format (no B-roll, like "It's just a robe") or the standard hook + robe part.
1a. **SOUND — mandatory, never skip (CLAUDE.md rules 9d + 9e, rule 31 Oct, Alex)**: cut the hook part of the reference (`hook-part.mp4`, from 0 to the hook end, WITH its sound); the Kling input is made later with `tools.py hookinput` (silent, last frame frozen). If anyone speaks: upload it and start Higgsfield `video_analysis_create` FIRST (WHO says WHAT; it can sit in the queue 5–20 min, so do steps 2–4 meanwhile; save it as `ref/analysis-<id>.json` — no analysis file = no hook generation). Then `python3 engine/audio3.py output/<name>/ref/hook-part.mp4 <hook end> output/<name>/a3 "<line from the analysis>"` (add `--no-voice` when the analysis says nobody speaks — song only) → the second of every word, the action sounds (look at `a3/events.jpg`), the background (music or room tone). Write the 3-layer SOUND block (CLAUDE.md 9e) for the hook prompt: words from the analysis, seconds from audio3, any full sentence after a pause 0.4 s EARLIER, room tone only (never music — our song comes in the edit). Never write "Silent" in a hook prompt when the original has speech.
2. **Name**: now that you know the video, pick a short folder name, e.g. `grinch-castle`, `grinch-hm`, rename `output/_new` to `output/<name>` and work there.
3. **Set**: `python3 engine/tools.py next-set <robe>` → character + room + B-roll variant (v4 or v5: motion clip, PRODUCT.md section, duration) + the fixed connector/remote + the song. LOOK at both photos (rule 1 in CLAUDE.md: real, light skin, face visible; room with a SOFA clearly visible). Bad one → `tools.py reject <that file>` + `next-set` again (it re-picks only that one). If the character photo shows legs, make the head + shoulders crop (`tools.py crop`, see PRODUCT.md). Upload the photo (or crop) and the room (save ids in state/media.json). Pick an under-robe outfit (Christmas pajamas, cozy sweater set, college sweatshirt — always long pants) and write it ONCE as one line in `output/<name>/outfit.txt` (e.g. `a red and white Fair Isle long pajama set`); from then on the hook prompt AND the B-roll `<OUTFIT>` copy that line word for word, never retyped (rule 31 Oct, Alex — same outfit in hook and B-roll), and from the room photo write `<SOFA>` (the real sofa and where it is) and `<COZY_BG>` (what is behind it) — **Room check** in CLAUDE.md.
4. **Start B-roll now** (it takes longest): the frozen prompt of PRODUCT.md section "B-roll v4" or "B-roll v5" (the one next-set printed), word for word, with its settings and media order (motion clip `<robe>_v4`/`<robe>_v5` as `video_references`, Image 1 woman, Image 2 room, then the robe refs; `<OUTFIT>` = the line in outfit.txt). (Skip for whole-clip formats.)
4b. **Hook = copy of the reference shot whenever possible** (HOOKS.md "Best way"): Kling video-edit on their own shot, with the action timeline + the spoken words with their seconds in the prompt. This is the approved method (motion and sound identical). Room photo has a table/object in the middle → first make the room without it (CLAUDE.md 7b). Use start frames (step 5–6) only when the shot needs something their video doesn't have.
5. **Start frames**: one per hook shot, recipe in `HOOKS.md`, all in one `generate_image_batch`. Download each with `python3 engine/tools.py fetch <url> output/<name>/start-<n>.jpg`, Read and check them (rules 6 in CLAUDE.md). Redo bad ones.
5b. **Hook sound check (rule 31 Oct, Alex)** — after the hook is generated: `python3 engine/tools.py compare-audio output/<name>/a3 <our hook> <hook end> output/<name>/a3-ours`. It is ADVICE ONLY: it prints the word starts side by side, extra words and dead-silent gaps; check music with `tools.py spectro <our hook> <out.jpg>`. Good picture but bad sound → CLAUDE.md 9e.5 (other try's sound if the cuts match within 0.05 s, `roomtone` for gaps). LISTEN to our hook next to the original yourself and regenerate ONCE only if you hear a real problem (wrong, missing or extra words, music, a word clearly more than 0.3 s off). The hook segment gets `"audio": true` in the edit.
6. **Animate** every good start frame (one `generate_video_batch`), recipe in `HOOKS.md`. Fetch each to `output/<name>/hook-<n>.mp4`, `sheet` at 4 fps, `safe-end` + 10 fps sheet of the end, decide start/end of the usable part. Copied hook → `python3 engine/tools.py compare <reference> <hook> <from> <to> output/<name>/compare.jpg` around each key action and Read it: every action must be in the same column as the original (same second, same speed — e.g. the robe falls as slowly as theirs). MAIN ACTION early by more than 0.3 s (unroll, reveal) → `python3 engine/tools.py hold <hook> <hook-held> <action start in ours> <action start in original> output/<name>/a3-ours` (lengthens the still part before the action, sound kept continuous, refuses if words would be cut); LATE by more than 0.3 s → the same command (negative shift = still part removed) (rule 31 Oct, Alex). Then `tools.py retime <hook-held> <reference hook> output/<name>/hook-exact.mp4 <hook end>` (trims to the original's hook end, keeps the sound, never changes speed) and look at a 10 fps sheet of the held part. Original with a long still part (> 2 s) before the action and hold looks wrong → second option: start frame + Kling image-to-video (HOOKS.md "Start frame"). Other differences (wrong object, missing action, glitch) → regenerate with the fix in the prompt. Redo bad ones (max 3 tries). If only a short usable piece survives (e.g. 1.2 s), see "Short hook" in HOOKS.md.
7. **B-roll** — it must NEVER go out with a glitch. Fetch to `output/<name>/broll.mp4`, then:
   a. `python3 engine/tools.py broll-check output/<name>/broll.mp4 motion/<robe>-<v4|v5>.mp4 output/<name>/broll-check` (on the UNCUT broll.mp4) — compares the shots with the motion clip, finds sudden jumps inside a shot (morph, a reference photo flashing in, a body part popping) and makes one sheet per shot.
   b. **v4 only, ALWAYS: `python3 engine/tools.py cutjerk output/<name>/broll.mp4 output/<name>/broll-cut.mp4`** (cuts 3.10–3.40 s, the robe-opening jerk; everything after comes 0.30 s earlier). Check 2.7–3.5 s at 15 fps (no jerk frame). From here on use `broll-cut.mp4`; its real cuts = `tools.py cuts output/<name>/broll-cut.mp4` (the clean cut at 3.10 is ours — not a shot change to avoid).
   c. Read EVERY `shotN.jpg` it made and tick each one: the same woman (face AND hair colour) in every shot, never an empty robe or a missing head, 5 fingers, robe = refs (hood, colours, trim), the room = our room photo with its REAL sofa, the cozy shot WIDE with her SITTING (v4) / lying (v5) on that sofa — never standing in front of it, no connector/remote/text anywhere, nothing melting. Feet, toes, socks or pajama legs are NOT a reason to redo (rule 31 Oct, Alex): only obvious long bare feet on the floor > 0.5 s → cut those frames in the edit if the cut stays clean, otherwise deliver.
   d. A shot fails (wrong face/room/robe, glitch, standing in the cozy shot — NOT feet) → regenerate ONCE with the SAME frozen prompt (never add words). Still failing → put the B-roll together from the 2 tries so every shot comes from a clean try (same person, room, robe — cut at the cuts); if one shot is bad in both, tell the creator which shot and why.
   e. In edit.json follow the edit times in PRODUCT.md, always 0.12 s away from every real shot change (the v4 jerk cut at 3.10 s is played straight through, inside the put-on + pockets segment). If the creator asked for a special last shot (`cozy: ...`) → do "Custom cozy" in CLAUDE.md instead (start it right after the B-roll, it takes a few minutes).
7b. **Connector + remote = the fixed clips, NEVER generated (rule 31 Oct, Alex)**: use exactly the files `tools.py next-set <robe>` printed — `products/<robe>/fixed/connector-fabric-1.mp4` (Grinch 0.05 → 1.70) and `remote-fabric-1.mp4` (0.3 → 3.0); the tree clips only if a fabric clip fails the check. As they are — no Kling, no upscale, no edits. Log them with `connector=<file> remote=<file>`.
8. **Edit**: write `output/<name>/edit.json` (format at the top of `engine/montage.py`) with the edit order from PRODUCT.md (hook → B-roll part 1 → connector → remote → B-roll cozy) and `"texts": []` — NO text in the video (rule 9, 28 Oct): the suggested text goes in `output/<name>/text.txt` + your message, for the creator to add in CapCut. (Old note, for the suggestion's timing only:) hook texts end where the call-to-action starts (the lying shot), or one text for the whole video. Place texts with `"segs": [first, last]` (segment numbers), never by hand-computed seconds — montage prints the real cut times. Music from the shared Christmas pool `music/xmas/` — `tools.py next-set <robe>` already picked the song and printed its drop + the edit.json lines; the drop/chorus ALWAYS lands on the hook → B-roll cut (CLAUDE.md rule 9n, also for Let It Go); log it with `song=<file>`. Run `python3 engine/montage.py output/<name>/edit.json`. Whole-clip formats with ceiling-fan cuts: after montage run `python3 engine/tools.py fanwipe <final> <final-2> <cut times…>` and keep the wiped one as FINAL.
9. **Check the final**: `sheet` at 1 fps and `cuts`; no on-screen text (rule 9), music quiet under the hook and full from the drop on the cut, the video never gets quieter after the hook, no leftover reference-photo flash, no black frames, ends cleanly. Fix and re-run if needed.
10. **Deliver** as described in CLAUDE.md (FINAL.mp4 + caption.txt + text.txt + short summary) and ALWAYS suggest 2 more hooks with this same B-roll (+ optional new cozy) — CLAUDE.md Delivery. Then `python3 engine/tools.py log <name> robe=<robe> hook="<concept>" outfit="<outfit>" music="<song + cue>" text="<first on-screen text>" motion=<v4|v5> connector=<file> remote=<file> song=<file> room=<room file> cozy="<cozy action or broll>"` so the next video is different.
